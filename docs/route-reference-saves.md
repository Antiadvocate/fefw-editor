## Player-observed Route file lifecycle

The player reported the following behavior on 16 November 2026:

1. Entering the Obelisk Chamber creates `Route_Led`, `Route_Kai`, etc. by
   copying the most recent `Auto`, before the game writes a new `Auto`.
2. Leaving the Obelisk Chamber creates `Route_Ism` for the main character
   (Eshmel). The exact copy/order relationship for this exit file was not
   separately specified.

This supersedes the earlier speculative route-switch creation trigger.
It is consistent with Route files acting as return-point snapshots; that
interpretation is separate from a traced runtime implementation. The current
two archives contain Auto and Chapter files, not before/after Route-file pairs,
so byte-for-byte copy identity has not been independently checked here.

`Route_*` snapshots and `Chapter_*` chapter-entry checkpoints are distinct.
This observation does not settle the natural Chapter-file creation trigger,
prove the meaning of timeline action 84, or require the editor to synthesize
Route files when changing chapters.
